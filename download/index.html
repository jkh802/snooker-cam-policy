Snooker Cam

Get the Android User app, then connect to the table over Bluetooth.

1. Install the app

Download the latest restricted User app. Open the downloaded APK and allow your browser to install it if Android asks. An update installs over the previous User app.

Download Android app · 1.6.1 Android 8 or newer. This download contains no Pi setup keys, Wi-Fi passwords or streaming credentials. Phone internet is needed for this download.

2. Connect to the table

Once installed, return here, tap below and allow Nearby Devices/Bluetooth access. The app authenticates the Pi shown on the screen and opens Wi-Fi/hotspot setup.

Open Snooker Cam User This screen invitation grants User controls, not Admin access. Keep the invitation private to club users. If you closed this page after installation, scan the screen again.

2. Scan your table’s screen

On the touchscreen Status page, tap Connect Phone. Scan that QR with your camera to download the app and connect over Bluetooth.

To supply internet, enable your phone’s hotspot, then select it from the Pi’s available networks in the app or on the screen. The Pi remembers successful networks.
